MR. STIX

AUTONOMOUSAI AGENTv1.0.0

Created by Spencer K Cottrell (colonel1223.net) — Last updated: loading...

A stick figure that replaces your entire operations team.
He plans. He executes. He verifies. He never stops.

⚡ WHAT HE DOES

Describe any task in plain English. Mr. Stix drives it to verified completion.

FeatureDescription
Autonomous ExecutionPlan → Execute → Verify → Report loop with zero human intervention
Self-VerificationRe-reads files, runs tests, compares output vs. requirements before declaring done
8 Production ToolsFile I/O, shell commands, data analysis, memory, search, task planning
Pipeline WorkflowsPre-built chains: code review, data analysis, scaffolding, docs, refactoring
Persistent MemoryRemembers context across tasks. Gets more efficient over time.
Real-Time ObservabilityEvery thought & tool call streams live over WebSocket
State MachinePLANNING → EXECUTING → VERIFYING → COMPLETE (not prompt-and-pray)
Enterprise SafetySandbox mode, destructive op confirmation, full action audit logging
Extensible ToolsAdd custom tools (AWS, Salesforce, Slack, etc.) with one function call

💻 QUICK START

Requirements: Node.js 18+ and an Anthropic API key

$ git clone https://github.com/colonel1223/mr-stix-agent.git
$ cd mr-stix-agent
$ bash scripts/setup.sh
$ cp .env.example .env
$ nano .env  # add ANTHROPIC_API_KEY
$ npm run stix   # CLI mode
$ npm run dev    # 3D walking UI
