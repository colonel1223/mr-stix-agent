Process

How He Works

01

You Describe the Task

In plain English. "Analyze this codebase and write a quality report." "Create a REST API with authentication and tests." "Read the CSV and find revenue anomalies."

02

Mr. Stix Plans

He restates the objective, identifies unknowns, decomposes the work into atomic steps with success criteria, maps dependencies, and prepares fallback approaches.

03

Mr. Stix Executes

Using real tools — reading files, writing code, running shell commands, analyzing data — he works through each step sequentially, adapting the plan based on what he discovers.

04

Mr. Stix Verifies

He re-reads every file he created, runs validation, and checks output against the original requirements. If anything is off, he fixes it automatically before reporting.

05

You Get Results

A structured report: what was accomplished, files created, commands run, verification results, and recommended next steps. The work is done. Verified. Real.

Get Started

Install in 60 Seconds

Requires Node.js 18+ and an Anthropic API key.

# Clone and setup
git clone https://github.com/colonel1223/mr-stix-agent.git
cd mr-stix-agent
bash scripts/setup.sh

# Add your API key
cp .env.example .env
nano .env

# Run
npm run stix   # Interactive CLI
npm run dev    # 3D UI + server

Three interfaces: Interactive CLI for terminal (npm run stix), REST API for integration (npm run agent), 3D desktop UI for monitoring (npm run dev).
