# 🎭 Mr. Stix's Dance Performance

*A mesmerizing display of ASCII choreography*

## The Performance

Mr. Stix has created an 8-frame dance sequence featuring:
- Opening stance (the classic pose)
- Arm movements (left up, both up, right up)
- The crossed-arms cool pose
- A dramatic jump with bent legs
- Landing crouch (for maximum effect)
- Return to stance (completing the cycle)

## Files

- `dance_frames.txt` - Static visualization of all dance frames
- `dance.py` - Animated dance performance script
- `README.md` - This file (you're reading the documentation of art)

## Running the Dance

```bash
python3 dance.py
```

The dance will run for 3 cycles by default, with each frame displayed for 0.8 seconds.

## Technical Specifications

- **Frames**: 8 unique poses
- **Duration per frame**: 0.8 seconds (optimized for dramatic effect)
- **Default cycles**: 3 (the perfect number for any performance)
- **Interruption**: Press Ctrl+C to stop (but why would you?)
